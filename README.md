# Fyren

**Ett mikrosteg räcker. Du behöver inte planera hela dagen nu.**

Fyren är en svensk wellness-app som hjälper användare att bygga hållbara rutiner, reflektera över sitt mående och navigera vardagen — ett steg i taget.

## Design

- **Plattform:** iOS (390×844)
- **Tema:** Mörkt (near-black bakgrund) med varma guldaccenter (#D4AF37)
- **Typografi:** Elegant sans-serif, tydlig hierarki
- **Estetik:** Premium, lugnt, minimalistiskt — som en fyr i mörkret
- **Språk:** Svenska genomgående

## Navigation

| Flik | Syfte |
|------|-------|
| **Liv** | Hemskärm, daglig översikt, kompassråd |
| **Fyrmål** | Mål, vanor, planering |
| **Dagbok** | Journalföring, reflektioner, tacksamhet |
| **Mer** | Profil, inställningar, premium |
